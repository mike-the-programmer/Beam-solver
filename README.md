Beam Solver

This project is a Python GUI application for structural beam analysis.

Features

* Draw beam spans
* Add supports
* Apply point loads
* Apply uniformly distributed loads (UDL)
* Generate Shear Force Diagram (SFD)
* Generate Bending Moment Diagram (BMD)

Technologies Used

* Python
* Tkinter
* NumPy
* Matplotlib
